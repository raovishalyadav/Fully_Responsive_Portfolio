## About

This repo powers my personal developer portfolio — styled as an interactive command-line session (`whoami`, `type stack.py`, `dir case_files`, etc.) that walks visitors through my experience, skills, and projects.

Sections on the site:

| Command | Section |
|---|---|
| `whoami` | Intro / who I am |
| `type stack.py` | Tech stack |
| `more access_log.txt` | Work experience |
| `dir case_files` | Projects |
| `more education_log.txt` | Education & achievements |
| `python connect.py` | Contact |

## Features

- 🖥️ Terminal / command-line aesthetic, fully custom (no template)
- 📱 Fully responsive — mobile, tablet, and desktop
- 🎨 Selectable color themes
- 🖱️ Custom cursor & custom scrollbar
- ⬆️ Scroll-to-top control
- 📄 One-click resume download
- ⚡ Zero dependencies — pure HTML/CSS/JS, loads fast

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — custom properties, responsive layout, theming
- **JavaScript** — interactivity (theme switch, cursor, scroll behavior)

## Getting Started

Clone and open locally — no build tools required:

```bash
git clone https://github.com/raovishalyadav/Fully_Responsive_Portfolio.git
cd Fully_Responsive_Portfolio
```

Then just open `index.html` in your browser, or serve it locally:

```bash
python -m http.server 8000
# visit http://localhost:8000
```
